Abstraction and Abstract classes

Q can a abstract class have a constructor.
-> Yes a abstract class can have Default, Paramatarise constructor but the only thing is that there will be no direct object creation. Because java needs an concreate implementation before creating a object.
-> So an abstract class cannot be initialized 

Q2 Can a abstract class have no abstract method 
-> Yes a abstract class may not have a abstractt method.

Q3 Can a abstract class have have final and static method 
-> Yes an abstract class can have final and static methods

Q4 An class constaning an abstract class needs to be abstract
-> Yes 

Rule -> If a subclass does not implement all abstract methods inherited from its parent, that subclass must also be declared abstract.
